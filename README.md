# Лиис — первый прототип

Это первый визуальный прототип сайта одной книги.

Сейчас намеренно стоят заглушки вместо текста: содержимое книги не придумано и не подменено.
Когда корпус глав будет собран, заменим названия и текст, сохранив ритм и архитектуру.

Файлы:
- index.html — структура страницы
- styles.css — визуальная система
- script.js — минимальная навигация

Откройте index.html в браузере.
